# نشاط (Nashat) — العرض التقني التفاعلي ومعمارية المنتج
### Interactive Technical Presentation & Architecture Showcase

موقع عرض تقني توثيقي وتفاعلي فائق الجودة لمنصة **نشاط (Nashat)**، مبني وفق أعلى معايير التصميم المخصصة للأنظمة التقنية (Front-End Design Without AI Slop)، بالاعتماد على الهوية البصرية الرسمية (`#111714` و `#B39A63`) والشعار الرسمي المعتمد (الكتاب المفتوح).

---

## 🌟 أبرز ميزات العرض التفاعلي

1. **تجربة ثنائية اللغة متكاملة (Bilingual RTL/LTR):**
   - دعم كامل وفوري للغتين العربية والإنجليزية.
   - تحول ديناميكي للاتجاه (`dir="rtl"` و `dir="ltr"`) وتكيف شامل للهياكل البصرية والمخططات التقنية.
   - صياغة احترافية وتربوية دقيقة مستوحاة من واقع الميدان التعليمي السعودي.

2. **الالتزام الصارم بالهوية وتفادي النمطية (No AI Slop):**
   - تصميم ذو طابع تحريري وهندسي رصين.
   - ألوان الهوية المعتمدة: خلفية داكنة خضراء عميقة (`#111714`) مع لمسات ذهبية معدنية متوازنة (`#B39A63`).
   - استعراض حقيقي لقطات الشاشة الميدانية من داخل المنصة الحية ولوحة تحليلات Vercel.

3. **الأرقام والمقاييس المعتمدة للمشروع (Authoritative Telemetry):**
   - **3,500+** مستخدم معتمد في كافة مناطق المملكة.
   - **5,000+** تقرير نشاط مدرسي رسمي مولد.
   - **1,500+** إذاعة مدرسية متكاملة الفقرات.
   - **500+** خطة نشاط مدرسي.
   - **5 ثوانٍ** زمن التوليد الذكي الفائق (مع محاكي لحظي لقياس السرعة).
   - **35%** معدل استبقاء المستخدمين.
   - **0 ر.س** تكاليف تشغيلية (اعتماد كامل على البنى المجانية عالية الكفاءة).
   - **130 ر.س** إيرادات مسجلة (اختبار أولي مع بقاء المنصة مجانية 100%).
   - تغطية شاملة لكافة مناطق المملكة الـ 13 عبر خريطة تفاعلية توضيحية.
   - توثيق رسمي من واقع لوحة تحليلات Vercel (1,500 زائر و5,909 مشاهدات و39% ارتداد).

4. **الهندسة المعمارية التفاعلية ومسار الطلب (Technical Architecture):**
   - مخطط تفاعلي للطبقات:
     - **الواجهة الأمامية:** Nashat Web Client على شبكة Vercel Edge.
     - **الخادم الخلفي:** ASP.NET Core API مستضاف على Somee.
     - **محرك الذكاء:** Gemini AI API.
   - مفتش تفاعلي للطبقات المعمارية (Layer Inspector) عند النقر على أي مكون.
   - متتبع مسار الطلب عبر 9 مراحل متعاقبة (من إدخال الفكرة حتى تصدير الـ PDF).
   - توثيق خاصية المعمارية عديمة الحالة (Stateless Architecture): عدم حفظ مسودات التقارير في أي قاعدة بيانات خارجية أو LocalStorage لحماية خصوصية المدارس.

5. **معرض آراء المستفيدين (Voices of Nashat):**
   - القسم الرئيسي الختامي للعرض.
   - 6 خانات مخصصة لاستقبال لقطات شاشة رسائل وانطباعات المستخدمين بنصوص عربية واضحة.
   - نصوص بديلة محايدة واحترافية: *"ستُضاف صورة رأي المستخدم هنا."*
   - هيكل مركزي في `src/data/testimonials.ts` لتسهيل إدراج الصور الحقيقية لاحقاً بضغطة زر.

## 🚀 كيفية التشغيل محلياً (Quickstart)

```bash
# 1. تثبيت الحزم (تم مسبقاً)
npm install

# 2. تشغيل خادم التطوير التفاعلي
npm run dev

# 3. بناء نسخة الإنتاج المعتمدة
npm run build
```

## 🖼️ كيفية إضافة صور آراء المستفيدين (Testimonials)

1. ضع صور لقطات الشاشة داخل المجلد: `public/assets/testimonials/` (مثال: `review-1.png`).
2. افتح الملف `src/data/testimonials.ts`.
3. ضع المسار أمام الخانة المرغوبة في خاصية `imageSrc`:
   ```typescript
   {
     id: 1,
     imageSrc: '/assets/testimonials/review-1.png',
     captionAr: 'رسالة إشادة من مشرف نشاط بمناسبة اليوم الوطني',
     captionEn: 'Supervisor feedback on Saudi National Day report generation',
     aspectRatio: 'aspect-[4/3]'
   }
   ```
4. سيتم عرض الصورة الحقيقية تلقائياً بدلاً من النص البديل دون الحاجة لتعديل كود الواجهة.
